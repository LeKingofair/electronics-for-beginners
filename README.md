# Electronics for Beginners

A hands-on learning path for students who have never touched a circuit before. Every project is cheap, works in the free [Tinkercad Circuits](https://www.tinkercad.com/circuits) simulator, and then moves to real hardware with an Arduino Uno.

No experience needed. If you can plug things in and copy-paste code, you can start.

## Learning Path

| # | Project | What you'll learn | Status |
|---|---------|-------------------|--------|
| 01 | [Blink LED](01-blink-led/) | Digital output, resistors, `delay()`, loops, arrays | Done |
| 02 | [LED + Button](02-led-button/) | Digital input, pull-up/pull-down resistors, debouncing, Serial Monitor | Done |
| 03 | [Night Light](03-night-light/) | Analog input, photoresistors, voltage dividers, PWM, calibration | Done |
| 04 | Temp & Humidity Display | Sensors, libraries, LCD | Coming soon |
| 05 | Parking Sensor | Ultrasonic sensor, buzzer | Coming soon |

## What You Need

- A free Tinkercad account (for simulation, no parts required)
- *Optional, for real hardware:* Arduino Uno (or a compatible clone), breadboard, LEDs, 220 Ω resistors, jumper wires, USB cable
- [Arduino IDE](https://www.arduino.cc/en/software) to upload code to a real board

## How to Use This Repo

1. Pick a project folder and read its README first.
2. Build the circuit in Tinkercad using the wiring guide.
3. Paste in the code, press **Start Simulation**, and watch it run.
4. Change something and see what happens. This is the best way to learn.
5. Build it on a real breadboard when you're ready.
